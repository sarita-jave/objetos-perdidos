# Objetos Perdidos · prototipo

Sitio estático, sin servidor ni base de datos.

- `index.html` → página web de Objetos Perdidos (`/`)
- `maquina/index.html` → pantalla de la máquina del punto de entrega (`/maquina/`)

Los datos son de ejemplo y se reinician al recargar la página.

## Publicación

El sitio se publica en Vercel automáticamente con cada cambio en la rama `main`.
